Hier finden Sie die Datenschutzerklärung und Kontaktmöglichkeiten zum Herausgeber. Die Seite enthält ausschließlich Dokumentation. Sie bietet keine Programmdateien, Zugangsdaten oder privaten Sitzungen an.

Support anfragen

  1. Öffnen Sie das Issue-Formular und wählen Sie Support, KI-Inhalt oder eine Datenschutzanfrage.
  2. Beschreiben Sie das Problem mit erfundenen Beispieldaten. Nennen Sie bei Bedarf die App-Version und Windows-Version.
  3. Entfernen Sie Nutzernamen, persönliche Pfade, Zugangsdaten und Inhalte privater Gespräche aus allen Angaben.
GitHub Issues sind öffentlich und erfordern zum Schreiben ein GitHub-Konto. Die Seite selbst kann ohne Konto gelesen werden. Posten Sie keine Geheimnisse oder personenbezogenen Inhalte. Support und vertrauliche Anfragen können Sie ohne GitHub-Konto an dragonluckyorigin@gmail.com senden. Übermitteln Sie nur notwendige Angaben und keine Zugangsdaten.

Problematische KI-Inhalte

Melden Sie den Typ des Problems und einen sicheren, möglichst synthetischen Reproduktionsfall. Kopieren Sie keine illegalen Inhalte, privaten Gespräche oder Daten anderer Personen in ein öffentliches Issue. Der Herausgeber prüft Meldungen, nimmt gegebenenfalls Inhalte aus diesem Supportbereich und bewertet erforderliche Dokumentations- oder Produktmaßnahmen. Diese Aussage verspricht keine Kontrolle über sämtliche Antworten fremder Modelle.
